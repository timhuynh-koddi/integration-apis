# Bid Manager Query Reports

> Source: Bid Manager API v2 REST Discovery document (https://doubleclickbidmanager.googleapis.com/$discovery/rest?version=v2, revision 20261111); reference https://developers.google.com/bid-manager/reference/rest. Fetched 2026-11-19. DV360 reporting runs through this API.

Used by koddi-offsite via: `queryService.Reports.Get` (`report_generator.go`); the report file is then downloaded over plain HTTP from the returned URL.

---

## queries.reports.get

`GET https://doubleclickbidmanager.googleapis.com/queries/{queryId}/reports/{reportId}`

Retrieves a report.

**Parameters**

| Name | In | Type | Required | Description |
|---|---|---|---|---|
| queryId | path | string (int64) | yes | Required. The ID of the query that generated the report. |
| reportId | path | string (int64) | yes | Required. The ID of the query to retrieve. |

**Response**: `Report`

---

## queries.reports.list

`GET https://doubleclickbidmanager.googleapis.com/queries/{queryId}/reports`

Lists reports generated by the provided query.

**Parameters**

| Name | In | Type | Required | Description |
|---|---|---|---|---|
| queryId | path | string (int64) | yes | Required. The ID of the query that generated the reports. |
| pageSize | query | integer (int32) |  | Maximum number of results per page. Must be between `1` and `100`. Defaults to `100` if unspecified. |
| orderBy | query | string |  | Field to sort the list by. Accepts the following values: * `key.reportId` (default) The default sorting order is ascending. To specify descending order for a field, add the suffix `desc` to the field name. For example, `key.reportId desc`. |
| pageToken | query | string |  | A token identifying which page of results the server should return. Typically, this is the value of nextPageToken returned from the previous call to the `queries.reports.list` method. If unspecified, the first page of results is returned. |

**Response**: `ListReportsResponse`

## Schemas

### `Report`

A single report generated by its parent report.

| Field | Type | Description |
|---|---|---|
| params | `Parameters` | The parameters of the report. |
| metadata | `ReportMetadata` | The metadata of the report. |
| key | `ReportKey` | The key information identifying the report. |

### `ListReportsResponse`

| Field | Type | Description |
|---|---|---|
| nextPageToken | string | A token to retrieve the next page of results. Pass this value in the page_token field in the subsequent call to `queries.reports.list` method to retrieve the next page of results. |
| reports | array<`Report`> | The list of reports. This field will be absent if empty. |

### `Parameters`

Parameters of a generated report.

| Field | Type | Description |
|---|---|---|
| metrics | array<string> | Metrics to define the data populating the report. Defined by [Metric](/bid-manager/reference/rest/v2/filters-metrics#metrics) values. |
| groupBys | array<string> | Dimensions by which to segment and group the data. Defined by [Filter](/bid-manager/reference/rest/v2/filters-metrics#filters) values. |
| type | string enum(REPORT_TYPE_UNSPECIFIED, STANDARD, INVENTORY_AVAILABILITY, AUDIENCE_COMPOSITION, FLOODLIGHT, YOUTUBE, GRP, YOUTUBE_PROGRAMMATIC_GUARANTEED, REACH, UNIQUE_REACH_AUDIENCE, FULL_PATH, PATH_ATTRIBUTION) | The type of the report. The type of the report determines the dimesions, filters, and metrics that can be used. Values: REPORT_TYPE_UNSPECIFIED - Default value when report type is not specified or is unknown in this version.; STANDARD - Standard report.; INVENTORY_AVAILABILITY - Inventory Availability report.; AUDIENCE_COMPOSITION - Audience Composition report.; FLOODLIGHT - Floodlight report.; YOUTUBE - YouTube report.; GRP - GRP report.; YOUTUBE_PROGRAMMATIC_GUARANTEED - YouTube Programmatic Guaranteed report.; REACH - Reach report.; UNIQUE_REACH_AUDIENCE - Unique Reach Audience report.; FULL_PATH - Full Path report.; PATH_ATTRIBUTION - Path Attribution report. |
| filters | array<`FilterPair`> | Filters to limit the scope of reported data. |
| options | `Options` | Additional report parameter options. |

### `ReportKey`

Identifying information of a report.

| Field | Type | Description |
|---|---|---|
| queryId | string (int64) | Output only. The unique ID of the query that generated the report. |
| reportId | string (int64) | Output only. The unique ID of the report. |

### `ReportMetadata`

The metadata of a report.

| Field | Type | Description |
|---|---|---|
| reportDataStartDate | `Date` | The start date of the report data date range. |
| status | `ReportStatus` | The status of the report. |
| googleCloudStoragePath | string | Output only. The location of the generated report file in Google Cloud Storage. This field will be absent if status.state is not `DONE`. |
| reportDataEndDate | `Date` | The end date of the report data date range. |

### `FilterPair`

Represents a single filter rule.

| Field | Type | Description |
|---|---|---|
| type | string | The type of value to filter by. Defined by a [Filter](/bid-manager/reference/rest/v2/filters-metrics#filters) value. |
| value | string | The identifying value to filter by, such as a relevant resource ID. |

### `Options`

Report parameter options.

| Field | Type | Description |
|---|---|---|
| includeOnlyTargetedUserLists | boolean | Whether to include data for audience lists specifically targeted by filtered line items or insertion orders. Requires the use of `FILTER_INSERTION_ORDER` or `FILTER_LINE_ITEM` filters. |

### `Date`

Represents a whole or partial calendar date, such as a birthday. The time of day and time zone are either specified elsewhere or are insignificant. The date is relative to the Gregorian Calendar. This can represent one of the following: * A full date, with non-zero year, month, and day values. * A month and day, with a zero year (for example, an anniversary). * A year on its own, with a zero month and a zero day. * A year and month, with a zero day (for example, a credit card expiration date). Related types: * google.type.TimeOfDay * google.type.DateTime * google.protobuf.Timestamp

| Field | Type | Description |
|---|---|---|
| month | integer (int32) | Month of a year. Must be from 1 to 12, or 0 to specify a year without a month and day. |
| year | integer (int32) | Year of the date. Must be from 1 to 9999, or 0 to specify a date without a year. |
| day | integer (int32) | Day of a month. Must be from 1 to 31 and valid for the year and month, or 0 to specify a year by itself or a year and month where the day isn't significant. |

### `ReportStatus`

The status of a report.

| Field | Type | Description |
|---|---|---|
| state | string enum(STATE_UNSPECIFIED, QUEUED, RUNNING, DONE, FAILED) | Output only. The state of the report generation. Values: STATE_UNSPECIFIED - Default value when state is not specified or is unknown in this version.; QUEUED - The report is queued to run.; RUNNING - The report is currently running.; DONE - The report has finished running successfully.; FAILED - The report has finished running in failure. |
| format | string enum(FORMAT_UNSPECIFIED, CSV, XLSX) | The format of the generated report file. Values: FORMAT_UNSPECIFIED - Default value when format is not specified or is unknown in this version.; CSV - CSV.; XLSX - Excel. |
| finishTime | string (google-datetime) | Output only. The timestamp of when report generation finished successfully or in failure. This field will not be set unless state is `DONE` or `FAILED`. |
