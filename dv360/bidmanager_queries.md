# Bid Manager Queries

> Source: Bid Manager API v2 REST Discovery document (https://doubleclickbidmanager.googleapis.com/$discovery/rest?version=v2, revision 20261111); reference https://developers.google.com/bid-manager/reference/rest. Fetched 2026-11-19. DV360 reporting runs through this API.

Used by koddi-offsite via: `queryService.Create/Run/Delete` (`app/integrations/dv360/reporting/report_generator.go`).

---

## queries.get

`GET https://doubleclickbidmanager.googleapis.com/queries/{queryId}`

Retrieves a query.

**Parameters**

| Name | In | Type | Required | Description |
|---|---|---|---|---|
| queryId | path | string (int64) | yes | Required. The ID of the query to retrieve. |

**Response**: `Query`

---

## queries.create

`POST https://doubleclickbidmanager.googleapis.com/queries`

Creates a new query.

**Request body**: `Query`

**Response**: `Query`

---

## queries.delete

`DELETE https://doubleclickbidmanager.googleapis.com/queries/{queryId}`

Deletes an existing query as well as its generated reports.

**Parameters**

| Name | In | Type | Required | Description |
|---|---|---|---|---|
| queryId | path | string (int64) | yes | Required. The ID of the query to delete. |

---

## queries.run

`POST https://doubleclickbidmanager.googleapis.com/queries/{queryId}:run`

Runs an existing query to generate a report.

**Parameters**

| Name | In | Type | Required | Description |
|---|---|---|---|---|
| queryId | path | string (int64) | yes | Required. The ID of the query to run. |
| synchronous | query | boolean |  | Whether the query should be run synchronously. When `true`, the request won't return until the resulting report has finished running. This parameter is `false` by default. Setting this parameter to `true` is **not recommended**. |

**Request body**: `RunQueryRequest`

**Response**: `Report`

---

## queries.list

`GET https://doubleclickbidmanager.googleapis.com/queries`

Lists queries created by the current user.

**Parameters**

| Name | In | Type | Required | Description |
|---|---|---|---|---|
| orderBy | query | string |  | Field to sort the list by. Accepts the following values: * `queryId` (default) * `metadata.title` The default sorting order is ascending. To specify descending order for a field, add the suffix `desc` to the field name. For example, `queryId desc`. |
| pageSize | query | integer (int32) |  | Maximum number of results per page. Must be between `1` and `100`. Defaults to `100` if unspecified. |
| pageToken | query | string |  | A token identifying which page of results the server should return. Typically, this is the value of nextPageToken, returned from the previous call to the `queries.list` method. If unspecified, the first page of results is returned. |

**Response**: `ListQueriesResponse`

## Schemas

### `Query`

A single query used to generate a report.

| Field | Type | Description |
|---|---|---|
| metadata | `QueryMetadata` | The metadata of the query. |
| queryId | string (int64) | Output only. The unique ID of the query. |
| schedule | `QuerySchedule` | When and how often the query is scheduled to run. If the frequency field is set to `ONE_TIME`, the query will only run when queries.run is called. |
| params | `Parameters` | The parameters of the report generated by the query. |

### `RunQueryRequest`

Details specifying how to run a query.

| Field | Type | Description |
|---|---|---|
| dataRange | `DataRange` | The date range used by the query to generate the report. If unspecified, the query's original data_range is used. |

### `Report`

A single report generated by its parent report.

| Field | Type | Description |
|---|---|---|
| params | `Parameters` | The parameters of the report. |
| metadata | `ReportMetadata` | The metadata of the report. |
| key | `ReportKey` | The key information identifying the report. |

|---|---|---|

### `QueryMetadata`

The metadata of the query.

| Field | Type | Description |
|---|---|---|
| shareEmailAddress | array<string> | List of additional email addresses with which to share the query. If send_notification is `true`, these email addresses will receive a notification when a report generated by the query is ready. If these email addresses are connected to Display & Video 360 users, the query will be available to them in the Display & Video 360 interface. |
| sendNotification | boolean | Whether an email notification is sent to the query creator when a report generated by the query is ready. This value is `false` by default. |
| title | string | The display name of the query. This value will be used in the file name of reports generated by the query. |
| format | string enum(FORMAT_UNSPECIFIED, CSV, XLSX) | The format of the report generated by the query. Values: FORMAT_UNSPECIFIED - Default value when format is not specified or is unknown in this version.; CSV - CSV.; XLSX - Excel. |
| dataRange | `DataRange` | The date range the report generated by the query will report on. This date range will be defined by the time zone as used by the advertiser. |

### `QuerySchedule`

Settings on when and how frequently to run a query.

| Field | Type | Description |
|---|---|---|
| startDate | `Date` | The date on which to begin the scheduled runs. This field is required if frequency is not set to `ONE_TIME`. Otherwise, it will be ignored. |
| endDate | `Date` | The date on which to end the scheduled runs. This field is required if frequency is not set to `ONE_TIME`. Otherwise, it will be ignored. |
| nextRunTimezoneCode | string | The canonical code for the timezone the query schedule is based on. Scheduled runs are usually conducted in the morning of a given day. Defaults to `America/New_York`. |
| frequency | string enum(FREQUENCY_UNSPECIFIED, ONE_TIME, DAILY, WEEKLY, SEMI_MONTHLY, MONTHLY, QUARTERLY, YEARLY) | How frequently to run the query. If set to `ONE_TIME`, the query will only be run when queries.run is called. Values: FREQUENCY_UNSPECIFIED - Default value when frequency is not specified or is unknown in this version.; ONE_TIME - Only when the query is run manually.; DAILY - Once a day.; WEEKLY - Once a week.; SEMI_MONTHLY - Twice a month.; MONTHLY - Once a month.; QUARTERLY - Once a quarter.; YEARLY - Once a year. |

If `CUSTOM_DATES` is assigned to this field, fields custom_start_date and custom_end_date must be set to specify the custom date range. Values: RANGE_UNSPECIFIED - Default value when range is not specified or is unknown in this version.; CUSTOM_DATES - Custom date range.; CURRENT_DAY - Current day.; PREVIOUS_DAY - Previous day.; WEEK_TO_DATE - All days, including the current day, since the most recent Sunday.; MONTH_TO_DATE - All days, including the current day, since the start of the current month.; QUARTER_TO_DATE - All days, including the current day, since the start of the current quarter.; YEAR_TO_DATE - All days, including the current day, since the start of the current calendar year.; PREVIOUS_WEEK - The previous completed week, beginning from Sunday.; PREVIOUS_MONTH - The previous completed calendar month.; PREVIOUS_QUARTER - The previous completed quarter.; PREVIOUS_YEAR - The previous completed calendar year.; LAST_7_DAYS - The previous 7 days, excluding the current day.; LAST_30_DAYS - The previous 30 days, excluding the current day.; LAST_90_DAYS - The previous 90 days, excluding the current day.; LAST_365_DAYS - The previous 365 days, excluding the current day.; ALL_TIME - All time for which data is available, excluding the current day.; LAST_14_DAYS - The previous 14 days, excluding the current day.; LAST_60_DAYS - The previous 60 days, excluding the current day. |

### `Date`

Represents a whole or partial calendar date, such as a birthday. The time of day and time zone are either specified elsewhere or are insignificant. The date is relative to the Gregorian Calendar. This can represent one of the following: * A full date, with non-zero year, month, and day values. * A month and day, with a zero year (for example, an anniversary). * A year on its own, with a zero month and a zero day. * A year and month, with a zero day (for example, a credit card expiration date). Related types: * google.type.TimeOfDay * google.type.DateTime * google.protobuf.Timestamp

| Field | Type | Description |
|---|---|---|
| month | integer (int32) | Month of a year. Must be from 1 to 12, or 0 to specify a year without a month and day. |
| year | integer (int32) | Year of the date. Must be from 1 to 9999, or 0 to specify a date without a year. |
| day | integer (int32) | Day of a month. Must be from 1 to 31 and valid for the year and month, or 0 to specify a year by itself or a year and month where the day isn't significant. |

### `ReportStatus`

| format | string enum(FORMAT_UNSPECIFIED, CSV, XLSX) | The format of the generated report file. Values: FORMAT_UNSPECIFIED - Default value when format is not specified or is unknown in this version.; CSV - CSV.; XLSX - Excel. |
